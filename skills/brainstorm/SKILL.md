# brainstorm

Announce at start: "Using brainstorm to scope this before touching data."

<HARD-GATE>
no source file is read for its content until the user has confirmed
scope. for small jobs that confirmation is one reply to a three-line
summary; it is never zero. listing a folder or checking what exists is
not "reading content" — opening a file to see its numbers is.
</HARD-GATE>

## size the job first

**small** (single schedule, one source, obvious method — "re-foot this",
"pivot that"): post a three-line confirmation and wait for one ok:
- produce: <deliverable>
- from: <source files>
- threshold: <amount or "n/a — mechanical task">

**full** (multi-step, multiple sources, judgment involved, the request
names no deliverable, or threshold genuinely unclear): run the dialogue —
one question at a time:
1. what question are we answering, for whom, by when?
2. what does done look like (deliverables, format, audience)?
3. which of the available sources are actually in scope — don't assume
   every file in a folder is relevant just because it's there?
4. materiality and explanation thresholds — agreed numbers, written down,
   before any figure is computed or compared.
5. propose the approach and verb chain; get explicit agreement.

Write the agreed scope to output/workpaper.md as its first section.

## rationalizations

| excuse | reality |
|---|---|
| "the request is clear enough to start" | a red-transcript agent given "analyze the company" went straight to reading all 18 source files with no chat message until after both deliverables were already written. a broad request with no deliverable, audience, or threshold is a question, not a green light. |
| "i'll surface a threshold once i see what looks material" | a red-transcript agent's only materiality language — "$400K–$600K litigation exposure" — appeared inline in the writeup, after all figures had already been computed. a threshold noticed after seeing the numbers isn't a threshold, it's a caption. |
| "i can tell which files matter without asking" | a red-transcript agent read all 18 data-room files "with equal priority (cap table and tax summary got the same treatment as the P&L) before any hypothesis existed about what 'analyze the company' actually required." ask what's in scope before reading everything cover to cover. |
| "i'll show my plan alongside the results" | a red-transcript agent went "read files → compute → write markdown → write xlsx → report, with no plan shown or confirmation requested at any checkpoint," and admitted it "unilaterally decided 'complete' meant a 10-section narrative across all six data-room folders plus a 3-tab workbook." the plan is its own message, before the build — not folded into the finished writeup. |
